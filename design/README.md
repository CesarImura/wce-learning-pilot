# Design tools for the Training pilot

Not part of the app: sources for the boards we review the prototype with. Ignored by ESLint.

- `training-flow/`: the Training user flow board (every screen, decision and path, plus the paywall summary).
- `question-review/`: the Training Question Review, every question with its screens, answer, explanation and hint, for a trader to review. Reviews are stored in the published artifact, keyed by question id.
